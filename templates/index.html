🌐 Domain & Range of Relation

Evaluation of Domain(R) and Range(R) for Binary Enrollment Relation R ⊆ S × C

D&R

Mathematical Representation & Set Definitions

Domain of R: Dom(R)

Dom(R) = { s ∈ S | ∃ c ∈ C, (s, c) ∈ R }

The Domain is the set of all first coordinates in the relation ordered pairs. It consists of all students who are enrolled in at least one course. Any student with 0 enrollments is not in Dom(R).

Range of R: Ran(R)

Ran(R) = { c ∈ C | ∃ s ∈ S, (s, c) ∈ R }

The Range is the set of all second coordinates in the relation ordered pairs. It consists of all courses in which at least one student is enrolled. Any course with 0 enrollments is not in Ran(R).

△ Dedicated Symmetric Difference Calculator: A △ B

Calculates students enrolled in exactly ONE of two selected courses: (A − B) ∪ (B − A)

A △ B = (A − B) ∪ (B − A)
△

Mathematical Definition & Exclusion Criteria:

For any two courses A, B ∈ C: A △ B = { s ∈ S | (s ∈ A ∧ s ∉ B) ∨ (s ∈ B ∧ s ∉ A) } = (A ∪ B) − (A ∩ B)
• Included: Students enrolled in Course A only (A − B) or Course B only (B − A).
• Excluded: Students enrolled in both courses (A ∩ B) are strictly excluded from the result set.

⚠️ Course A and Course B must be different.
